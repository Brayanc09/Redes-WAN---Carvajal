En esta sección se diseñan las redes IP. Se pueden utilizar varias redes principales y distribuir los segmentos mediante VLSM.

Topología

Este módulo utilizará posteriormente las redes y segmentos calculados en VLSM para construir la topología lógica de la red.

Ciberdefensa

Este módulo verificará que la configuración generada no contenga prácticas inseguras.

  • No guardar contraseñas ni secretos.
  • Validar las entradas del usuario.
  • Detectar configuraciones inseguras.
  • Aplicar principio de mínimo privilegio.
  • Reducir la superficie de ataque.
Este módulo se implementará después de Configuración.
