# NetBuilding

Herramienta académica para diseño y gestión de redes WAN.

## Versión actual
V2.2.0

## Base conservada
La versión V2.1.1 del dashboard se conserva sin eliminar sus funcionalidades.

## Orden de desarrollo
1. Subnetting
2. Topología
3. Configuraciones
4. Ciberdefensa

## Estructura
- `frontend/`: interfaz web.
- `backend/`: lógica futura que requiera procesamiento adicional.
- `tests/`: pruebas automatizadas.
- `versions/`: versiones estables del proyecto.
- `.env.example`: plantilla de variables locales.
- `.gitignore`: evita subir archivos temporales o secretos.

## Regla de seguridad
Nunca guardar contraseñas, tokens, claves privadas o datos reales de clientes en el código ni en Git.
